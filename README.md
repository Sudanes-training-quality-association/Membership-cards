# نظام إصدار بطاقات العضوية — Membership Card Generator
الجمعية السودانية لجودة التدريب · Sudanese Training Quality Association

تطبيق ويب (PWA) بلغة HTML/CSS/JavaScript فقط، بدون خادم أو قاعدة بيانات.

## التشغيل محلياً
خدمة الـ Service Worker تحتاج `http://` وليس فتح الملف مباشرة. من داخل المجلد:
```
python3 -m http.server 8000
```
ثم افتح http://localhost:8000 (التصدير والطباعة يعملان أيضاً بفتح index.html مباشرة، لكن التثبيت والعمل دون اتصال لا يعملان).

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع جميع الملفات في الجذر (index.html وبقية الملفات والمجلد assets).
2. Settings ← Pages ← Source: *Deploy from a branch* ← الفرع `main` والمجلد `/ (root)` ← Save.
3. افتح الرابط https://USERNAME.github.io/REPO/ — كل المسارات نسبية فتعمل داخل المستودع.
4. بعد أول تحميل ناجح يعمل التطبيق دون اتصال ويمكن تثبيته من المتصفح.

## المقاس والتصدير
- البطاقة 90 × 90 مم عند 300 DPI = 1063 × 1063 بكسل، ولا تتأثر بحجم الشاشة.
- PNG / JPG / WEBP بالدقة نفسها (مع وسم 300 DPI في PNG وJPG). PNG وWEBP بزوايا شفافة، وJPG وPDF بخلفية بيضاء.
- PDF صفحة واحدة بمقاس 90 × 90 مم بالضبط. البطاقة تُرسم كصورة عالية الدقة داخل الـ PDF، فالنص العربي محفوظ بشكله الصحيح لكنه غير قابل للتحديد.
- الطباعة المباشرة تستخدم `@page { size: 90mm 90mm }`؛ اختر "الهوامش: لا شيء" و"المقياس 100%" في نافذة الطباعة.

## الخط
يُحمَّل خط Cairo من Google Fonts ويُخزَّن تلقائياً للعمل دون اتصال. لاستقلال كامل، نزّل الخط إلى `assets/fonts/` وأضف `@font-face` في style.css.

## الملفات
